# 모아 · JEV Workplace 기능별 화면 갤러리

JEV의 실제 의미 판단(System One Choice)과 `@json-render/react` 인터랙티브 컴포넌트로 렌더링된 각 기능별 전체 화면 캡처 모음입니다.  
모든 화면은 UI 잘림 없이 상단 헤더, 사이드바, 자연어 질문 말풍선, 컴포넌트 본문, 반응 메타데이터(JEV 왕복/판단 시간, 토큰, 비용), 입력 폼까지 전체를 포함하고 있습니다.
